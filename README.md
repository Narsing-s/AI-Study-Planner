# AI Study Planner

A lightweight, responsive study-planning app that turns a learning goal, available time, level, and deadline into a practical roadmap.

## MVP
- Personalized multi-day study plan
- Daily learning + practice + revision tasks
- Progress tracking with local persistence
- Practice quiz
- Responsive dashboard
- GitHub Pages deployment
- No account or paid API required

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Roadmap
1. Adaptive planning from real completion history
2. AI-generated explanations and quizzes
3. Spaced-repetition engine
4. Calendar export and reminders
5. Optional authentication and cloud sync
